About Password Strengthening System

Password Strengthening System is a modern cybersecurity tool crafted to help users audit and elevate their credential security.


Developed by A0nup as part of practical cybersecurity tooling, it features NIST SP 800-63B aligned evaluation metrics, cryptographic entropy assessment, and zero-compromise client-side execution.


🛡️ Dual Execution: Runs seamlessly serverless on GitHub Pages / Netlify and features a Python REST API backend.
🔐 Zero Data Retention: Passwords evaluated are never logged or stored.
⚡ Cryptographic Strength: Generated keys utilize CSPRNG algorithms (secrets in Python and crypto.getRandomValues in browser).

How It Works

1. Entropy & Scoring Rubric

Passwords are scored across 5 key dimensions:

  • Length: 8 or more characters (adds +1 score)
  • Uppercase (A-Z): Broadens character search space
  • Lowercase (a-z): Standard character pool
  • Digits (0-9): Mitigates pure dictionary attacks
  • Special Characters: Exponentially expands brute force search space

2. Brute-Force Resistance Formula

The total keyspace is calculated as N = R^L, where R is the pool of possible characters and L is length. A 16-character complex password requires quadrillions of computing years to crack.
